# Buchdatei (nicht öffentlich)

Lege das bezahlte Buch hier ab:

```
private/books/sternzeichen-in-balance.pdf
```

Die Datei darf **nicht** unter `public/` liegen und nicht ins öffentliche
GitHub-Repo. Download nur über den signierten Link nach einer bezahlten
Stripe-Session.

Production: Datei lokal halten und per Vercel-CLI mitdeployen, oder
`BOOK_PDF_URL` auf einen privaten HTTPS-Link setzen.
